# HW2 建置資料庫與匯入測試資料 — 線上書店訂購管理系統

## 資料夾內容

```
HW2_DBandETL/
├── HW2_DBandETL_學號.zip          ← 繳交用（請把「學號」改成自己的學號）
├── submission/                    ← zip 的內容
│   ├── HW2_線上書店資料庫.accdb    ① Access 資料庫（已建表、已匯入）
│   ├── HW2_假資料工作檔.xlsx       ② 亂數生成工作檔（每格都是公式）
│   ├── HW2_匯入資料.xlsx           ③ 匯入用資料檔（純值）
│   ├── AI生成說明與Prompt.md
│   └── AI生成內容/                 產生以上檔案的程式
└── scripts/                       同上程式（build.sh 一鍵重建）
```

## 資料庫設計

```
類別 1 ─┐
        ├─ ∞ 書籍 1 ─┐
出版社 1 ┘           ├─ ∞ 訂單明細
會員 1 ─ ∞ 訂單 1 ───┘
```

完整欄位規格（型別、大小、驗證規則、範圍、產製公式）見工作檔的「欄位規格」頁；
逐表設計時做的調整見「說明」頁第四節。

## 自己在 Access 裡做一次匯入（建議練習）

`.accdb` 已經匯入好資料。若要親手練習匯入：

1. 開啟 `HW2_線上書店資料庫.accdb`，依「訂單明細 → 訂單 → 會員 → 書籍 → 出版社 → 類別」順序清空資料（先子後父）
2. 外部資料 → 新增資料來源 → 從檔案 → Excel → 選 `HW2_匯入資料.xlsx`
3. 選「在資料表中附加記錄的複本」，選對應的資料表 → 選同名工作表 →「第一列是欄名」→ 完成
4. 依「類別 → 出版社 → 書籍 → 會員 → 訂單 → 訂單明細」順序匯入（先父後子，否則參考完整性會擋下）

## 重新產生亂數資料

- Excel：開啟工作檔按 F9 → 確認「檢核」頁合計為 0 → 各表 複製 → 選擇性貼上「值」到匯入檔
- 或用程式：`scripts/build.sh`（需 python3 + openpyxl、LibreOffice、Java 17+、Maven）
